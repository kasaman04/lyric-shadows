# 2文をつなぐ

ホームの旧「AIと話す」は、この音声ゲームに置き換えました。旧会話APIはマウントしません。旧ページURLは `/sentence-game.html` に移動します。既存の会話データは削除せず、新ゲームの保存先と分離します。

1. 基本10種類、応用7種類、または個別の表現を選ぶ。
2. 「はじめる」でマイクを許可。ランダムな2文をElevenLabsで再生する。
3. 音声要素の `ended` を受けて録音開始。5秒以内に発話がなければ「回答なし」。話し始めた場合は5秒制限を解除し、1.6秒の無音で自動提出する（最大45秒）。録音は問題音声の再生中には開始しない。
4. OpenAIで英語音声を書き起こし、2文の意味を保つ1文になっているか採点。お手本との完全一致は要求しない。
5. 結果と短い解説、お手本音声。同じ問題を再挑戦するか、次のランダム問題へ進む。

基本: who, whom, whose, which, that, what, when, where, why, how。
応用: whoever, whomever, whatever, whichever, whenever, wherever, however。
what は先行詞を含む関係代名詞、how は方法の表現として扱います。however は方法・程度の用法です。「しかし」の接続副詞用法は対象外です。

`OPENAI_API_KEY` と `ELEVENLABS_API_KEY` はサーバーにのみ設定。既存のキーを使用します。任意設定: `OPENAI_TRANSCRIPTION_MODEL`、`SENTENCE_GAME_GRADING_MODEL`、`SENTENCE_GAME_VOICE`（ElevenLabs voice ID）、`SENTENCE_GAME_TTS_MODEL`。

保存先は標準で `data/sentence-game`。`SENTENCE_GAME_STORAGE=supabase` または既存の `PET_STORAGE=supabase` の場合は同じSupabase接続の非公開 `sentence-game` バケットを使います。`SENTENCE_GAME_STORAGE=local` でローカル保存に固定できます。音声は問題文・モデル・声から生成したIDでキャッシュし、録り直しでは再生成しません。回答の採点も同じ試行IDでは重複実行しません。公開APIから模範解答が返るのは採点後です。

マイクを使う前にiOSの音声セッションを `play-and-record` にし、終了・離脱時にマイクを停止します。画面を離れた場合は無回答扱いにせず中断します。APIエラーは採点の不正解にせず再試行できます。

マイクの許可取得は練習の初回だけです。問題を変える・同じ問題を繰り返す・採点するたびに `getUserMedia` を呼び直しません。練習中は同じ生存中のストリームを保持し、録音時以外は音声トラックをミュートします。録音器だけ問題ごとに新しくします。終了・ページ離脱・バックグラウンド移行時にはトラックを停止して解放し、次の練習開始時に再取得します。

検証: `node --test test/sentence-game*.test.cjs`。実API確認: `node scripts/check-sentence-game.js`（合成した英文のみ使用、キーは出力しない）。

## モンスターの生存条件

生存には、従来の「時間」と「毎日10回の音声回答」の両方が必要です（policy: both）。時間は経過で減り、英語を聴くと聴いた秒数の24倍回復します。30分で12時間、1時間で24時間ぶん、最大24時間まで回復します。お世話や10回達成だけでは時間を回復しません。正誤は不問で、同じ問題の再挑戦も1回。無回答、空の音声認識結果、お手本の再生だけは回数に数えません。

日本時間0:00〜24:00で集計。10回未満の日があれば、その日の終了時に死亡します。10回達成しても時間が0なら死亡し、時間が残っていても10回未達なら死亡します。両方が不足した場合は最初に不足した時刻を死亡時刻にします。アプリを閉じている場合も次回接続時に両方を判定します。新しい相棒の回数条件は翌日の最初の丸一日から適用しますが、時間条件は初日から有効です。余分に回答しても翌日への繰越はありません。

旧daily-onlyデータの移行では、現在の残り期限を24時間の上限内で引き継ぎ、新しい時間台帳の基準に固定します。移行を繰り返しても時間は増えません。既存の10回集計、開始日、残高、成長、図鑑、復習ノートを保持し、過去の再生記録で時間を二重回復しません。すでに終了した歴代の相棒は変更しません。遅れて届いた録音や再生の証拠でも、両方の条件を満たさない限り復活しません。

採点済み試行IDをサーバーで重複排除し、音声回答を受信したサーバー時刻の日付に加算します。締切前に届いた10回目の採点が遅れても、正しい提出日に計上します。育成保存に失敗した場合も、採点済みの結果を再利用して回数だけ同期します。端末IDは試行開始時のCookieに固定し、回答送信時に差し替えません。

聴いた時間・成長・コインによるお世話は継続します。毎日の回数はゲーム画面と育成画面に表示します。検証: `node --test test/pet-practice.test.cjs test/sentence-game.test.cjs`。

時間との併用・移行・遅延データ・端末上の先行表示の検証: `node --test test/pet-combined-life.test.cjs test/pet-listening-life.test.cjs`。

## 復習ノート

「間違い」「あと少し」「無回答」の採点済み問題を、同じ端末の育成データ `sentenceReview` に自動保存します。同じ問題は1件にまとめ、正解し直しても消しません。出題時の2文・解答・日本語訳・解説をノートに保持します。

練習画面の「復習ノート」から一覧を開き、問題を選びます。元の2文と、それぞれの英文の下の日本語訳は常に表示。「答えを見る」を押した後だけ解答・答えの日本語訳・解説と「答えの音声を聞く」を表示します。答えを隠す、前後の問題へ移動、一覧へ戻る、再読み込み後の復習ができます。以前に保存した問題も、英文が現在の問題集と一致する場合は日本語訳を補って表示します。保存済みの英文や学習記録は書き換えず、音声は既存のキャッシュを再利用します。問題2文の音声も聞けます。復習ではマイクを取得せず、自動録音や採点は実行しません。ノートへ切り替えたら練習中のマイクを解放します。閲覧・音声再生は1日10回の音声回答には含めません。

一覧APIは解答を含まず、解答は明示的なreveal操作で取得します。音声生成は保存された問題の2文または解答だけを対象とし、既存のElevenLabs音声キャッシュを共有します。ノートは公開サーバーの育成保存先（Supabase）に残り、再デプロイでも消えません。過去の回答については、保存済みの直近7日分の練習レシートから取り込める記録を24件ずつ確認します。古い無回答など、索引のない記録は対象外です。

UI検証: `python scripts/verify-sentence-review-browser.py`。保存・端末分離・音声キャッシュ・過去データ取り込みは `test/sentence-game.test.cjs`。
