# 映画の会話学習

本体ホームの「映画」タブ（`/#movies`）から開きます。ビフォア三部作30会話、エターナル・サンシャイン13会話、グッド・ウィル・ハンティング10会話、トゥルーマン・ショー7会話、合計60会話を収録しています。三部作は個別の作品も選べます。

作品カードから本体内の縦型プレイヤーに入り、上下のスワイプ・スクロール・矢印キーで会話を移動します。字幕切替、再生位置、等速再生、リピート、会話の保存に対応しています。速度変更ボタンを省き、再生・一時停止ボタンを大きく表示します。再生バーの「5秒戻る」を押すたびに、現在位置から5秒巻き戻します。冒頭5秒以内では0秒へ戻り、再生中・一時停止中の状態は保ちます。字幕と再生位置も更新します。英語以外の台詞は日本語訳のみを表示します。戻るボタンで映画一覧に戻り、再生とプレイヤーのイベント処理を終了します。再生中は既存のリスニング時間集計を利用し、育成の浮動バッジは非表示にします。

## 50回視聴した会話

各会話の音声を最後まで再生すると視聴回数を1回増やし、50回に達した会話を一覧と全作品フィルターから自動で非表示にします。元の動画ファイルは保持します。視聴回数は端末IDに紐づけてブラウザと既存の学習記録サーバーの両方に保存し、日付が変わっても累積します。同じ端末IDを復旧したブラウザでも引き継ぎます。以前のブラウザ内の回数は初回に移行します。通信できない間の回数はブラウザに保持し、次回起動時・画面復帰時・通信復帰時に同期します。各画面の加算を個別に記録し、再送や古い応答による減少・重複を防ぎます。途中のスワイプや末尾へのシーク、ミュート・音量0での再生は1回に数えません。各再生で音声オンで実際に通過した範囲を確認し、95%以上を再生して終端に到達した場合だけ数えます。リピートも1周ごとに1回です。選んだ作品の会話がすべて完了した場合は完了画面を表示し、別の作品の選択と一覧へ戻る操作を使えます。

## 保存先

- `public/movie-study/media/`: 音量調整済み動画60本
- `public/movie-study/posters/`: 一覧とプレイヤーの画像
- `data/movie-scenes.json`: 会話の情報と字幕
- `public/movie-study-data.js`: 本体で読み込む同じデータ
- `public/movie-study-progress.js`: 視聴回数の保存と1回の再生範囲の確認
- `public/movie-study.js` / `movie-study.css`: 本体用プレイヤーと映画一覧

動画・画像・字幕は本体と同じサーバーから配信します。以前のデモ用サーバーや別ポートには依存しません。Expressの静的ファイル配信で動画のRangeリクエストにも対応します。

## デモから更新する

本体のディレクトリで次を実行します。

```powershell
python scripts/import-movie-study.py
```

標準の取り込み元は、親ディレクトリの `output/before-sunrise-demo` です。`--source <path>` で変更できます。公開対象の動画・画像・字幕だけを取り込み、同じサイズ・更新日時のメディアはコピーを省略します。アプリの起動に取り込み元は不要です。

`--include-player` を付けると取り込みスクリプト内の変換処理に従い、デモのプレイヤーも本体向けに再生成します。本体向けの変更はスクリプト側に保管してください。

字幕の記録は自動照合によるもので、全場面を人が実際に聞いた確認を示すものではありません。`subtitleVerification` にもその区別を保存しています。2026-11-19の追加では、公開クリップ20本から自然な会話22件を切り出しています。音声認識と単語単位の同期はPC内で実施し、公開字幕テキストの整理・日本語訳・意味の照合にAPIを使用しています。追加した音声・動画は文字起こしAPIへ送信していません。エターナルのナオミとの電話は削除シーンとして明示しています。新規会話も約−16 LUFSに調整し、AAC書き出し後のピークを確認しています。動画は再生対象だけ読み込むため、会話数が増えても全動画を一度に取得しません。
