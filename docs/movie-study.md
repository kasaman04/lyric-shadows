# 映画の会話学習

本体ホームの「映画」タブ（`/#movies`）から開きます。ビフォア三部作19会話とエターナル・サンシャイン8会話、合計27会話・約49.5分を収録しています。三部作は個別の作品も選べます。

作品カードから本体内の縦型プレイヤーに入り、上下のスワイプ・スクロール・矢印キーで会話を移動します。字幕切替、再生位置、速度、リピート、会話の保存に対応しています。英語以外の台詞は日本語訳のみを表示します。戻るボタンで映画一覧に戻り、再生とプレイヤーのイベント処理を終了します。再生中は既存のリスニング時間集計を利用し、育成の浮動バッジは非表示にします。

## 100回視聴した会話

各会話の音声を最後まで再生すると視聴回数を1回増やし、100回に達した会話を一覧と全作品フィルターから自動で非表示にします。元の動画ファイルは保持します。視聴回数はこのブラウザのローカルストレージに保存し、再読み込み後も引き継ぎます。途中のスワイプや末尾へのシーク、ミュート・音量0での再生は1回に数えません。各再生で音声オンで実際に通過した範囲を確認し、95%以上を再生して終端に到達した場合だけ数えます。リピートも1周ごとに1回です。選んだ作品の会話がすべて完了した場合は完了画面を表示し、別の作品の選択と一覧へ戻る操作を使えます。

## 保存先

- `public/movie-study/media/`: 音量調整済み動画27本
- `public/movie-study/posters/`: 一覧とプレイヤーの画像
- `data/movie-scenes.json`: 会話の情報と字幕
- `public/movie-study-data.js`: 本体で読み込む同じデータ
- `public/movie-study-progress.js`: 視聴回数の保存と1回の再生範囲の確認
- `public/movie-study.js` / `movie-study.css`: 本体用プレイヤーと映画一覧

動画・画像・字幕は本体と同じサーバーから配信します。以前のデモ用サーバーや別ポートには依存しません。Expressの静的ファイル配信で動画のRangeリクエストにも対応します。

## デモから更新する

本体のディレクトリで次を実行します。

```powershell
python scripts/import-movie-study.py
```

標準の取り込み元は、親ディレクトリの `output/before-sunrise-demo` です。`--source <path>` で変更できます。公開対象の動画・画像・字幕だけを取り込み、同じサイズ・更新日時のメディアはコピーを省略します。アプリの起動に取り込み元は不要です。

`--include-player` を付けると取り込みスクリプト内の変換処理に従い、デモのプレイヤーも本体向けに再生成します。本体向けの変更はスクリプト側に保管してください。

字幕の記録は自動照合によるもので、全場面を人が実際に聞いた確認を示すものではありません。`subtitleVerification` にもその区別を保存しています。今回の組み込みでは動画の追加ダウンロードや外部APIへの送信は行っていません。
