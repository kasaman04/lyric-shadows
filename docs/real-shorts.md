# リアル英会話

ホームの「リアル」タブ、または `/#shorts` から開きます。ランダムチャット13本、デート4本、街頭インタビューと日常の掛け合い各10本を収録しています。

2026年11月28日にランダムチャットへ5本追加し、出題と答え合わせが中心の2本を一覧から外しました。追加分は趣味や言語、学び方の話で、相手の発言を受けた質問や返答を含む場面です。追加分には新しいIDを割り当て、一覧から外した会話の保存済み視聴回数は引き継ぎます。

デートには、イギリスとアイルランドの初デート番組の会話を収録しています。初対面の挨拶、飲み物の注文、共通点を見つける会話、次も会いたいか伝える場面です。映像は横長の比率を保って再生します。

映画と共通の縦スワイププレイヤーを使い、ジャンルの選択、等速再生、5秒戻し、リピート、会話の保存、リスニング時間の集計に対応します。焼き込み字幕がある動画はその表示を保ち、アプリの字幕欄に英語と日本語訳を時刻に合わせて表示します。初期表示は英日で、字幕ボタンから英日・英語のみ・日本語のみ・非表示を切り替えられます。

視聴回数は映画と同じブラウザ・サーバーの記録に、専用の会話IDで保存します。音声オンで95%以上を実際に再生して最後に達した場合に1回と数えます。リアルの会話は20回、映画の会話は50回で一覧から非表示になります。保存済みの回数も判定に使い、目標回数を超えた記録も保持します。

- `data/real-shorts-scenes.json`: 出典、切り出し区間、字幕、固定ID
- `public/real-shorts-data.js`: ブラウザ用データ
- `public/real-shorts/media/`: 音量調整済みのMP4
- `public/real-shorts/posters/`: 元動画から抽出した画像
- `public/real-shorts.js` / `real-shorts.css`: ジャンル一覧と縦型画面
- `scripts/import-real-shorts.py`: レビュー済みのローカル素材からの取り込み
- `scripts/movie_player_options.py`: 映画プレイヤーの再生成時にも共通設定を維持

字幕は端末内の独立した音声認識、公開英語字幕または動画内の字幕、抽出した映像フレームで照合し、日本語訳を文面で確認しました。追加分の字幕時刻は単語の認識時刻に合わせています。全編を人が実聴した記録ではありません。動画・音声は外部の文字起こしAPIへ送信していません。

再取り込みには、追加する会話だけを記載したレビュー済みマニフェストと素材のフォルダを指定します。取り込みは既存データへ固定IDで結合し、同じIDを別の動画に転用すると停止します。公開後の再生は取り込み元のフォルダやデモ用サーバーに依存しません。
