# イラスト暗記カード

TOPの「2文をつなぐ」と学習タブの間から開く。最初のセットは「動詞が続く表現」の20枚。表のイラストと日本語訳から英文を思い出して、カードをタップすると英文と文型が表示される。スピーカーボタンでElevenLabsの米国英語音声（Mark）を再生できる。音声ファイルは `public/flashcard-audio/<id>-v1.mp3`。

「覚えた」はその周の出題から外し、「もう一度」は残りの列の最後に移す。現在のカードと進捗は端末のブラウザに保存する。全枚完了後は「もう一周する」からやり直せる。

カードの教材は `public/flashcards-data.js`、画像は `public/flashcard-images/<id>.webp`。画像には英文や日本語訳を入れない。既存会話フレーズ用の、英文ラベルを焼き込む画像とは別に管理する。
